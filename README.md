# 📸 Arte Digital Floripa

O **Arte Digital Floripa** é um acervo digital online projetado para curadoria e exibição de registros fotográficos. O sistema permite que usuários autenticados realizem o upload de imagens, organizando-as em uma galeria pública e acessível, preservando a memória visual da cidade.

## 🎯 Objetivo do Projeto
Transformar um conjunto de fotos físicas ou esparsas em um repositório digital organizado, facilitando a visualização e a gestão desse conteúdo através de uma interface intuitiva e um sistema de backend robusto.

## 🚀 Fluxo de Trabalho (Git)
Para manter a organização, seguimos as seguintes regras:

1. **`main`**: Apenas código estável e revisado.
2. **`development`**: Branch de integração entre Front e Back.
3. **`frontend` / `backend`**: Branches principais de cada equipe.
4. **Features**: Para cada tarefa, crie uma branch a partir da sua área (ex: `feat/login-page`).

** TALVEZ EU ELIMINE ESSE NÚMERO 4 PARA EVITAR DÚVIDAS

> **Nota:** Todos os merges para `main` e `development` exigem Pull Request e aprovação dos líderes.
